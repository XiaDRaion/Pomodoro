Pomodoro
----------------------------------------------------------
Hi! This is a simple Pomodoro timer application that helps you manage your time effectively using the Pomodoro Technique. The Pomodoro Technique is a time management method that uses a timer to break work into intervals, traditionally 25 minutes in length, separated by short breaks.

You can use this application to set your work intervals and breaks, allowing you to stay focused and productive throughout your tasks. Integrated with youtube, you can also listen to your favorite music while working
